# homebrew-caskvet

Homebrew tap for [caskvet](https://github.com/breichr/caskvet) — a
read-only supply-chain health report for the Homebrew casks installed
on your Mac.

## Install

```sh
brew install breichr/caskvet/caskvet
```

## Updating

The formula follows the caskvet releases; it is updated by hand after
each tagged release.
